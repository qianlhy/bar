# 微信公众平台提审配置清单

以下项目必须在微信公众平台人工确认；代码无法代替平台配置。

## 1. 服务类目与资质

- 按实际经营范围选择餐饮、酒类相关服务类目，并上传仍在有效期内、主体一致的许可证件。
- 酒类商品仅保留现有资质允许经营的范围；无法确认资质覆盖的商品不要提审。
- 审核说明写明：本小程序用于梭哈酒馆南京店店内商品浏览、点单和订单支付，酒类入口前有“已满 18 周岁、理性饮酒”确认。
- 不要在资质尚未确认时自行填写具体类目名称或承诺配送范围，以公众平台当前可选类目和审核要求为准。

## 2. 服务器域名

在“开发管理 → 开发设置 → 服务器域名”中配置：

- request 合法域名：`https://bar.twst.work`
- uploadFile 合法域名：`https://bar.twst.work`
- downloadFile 合法域名：`https://bar.twst.work`

保存前确认域名 HTTPS 证书有效、无重定向到其他域名。当前代码已开启正式域名校验，不能再依赖开发工具的“不校验合法域名”。

## 3. 用户隐私保护指引

- 在公众平台完成《用户隐私保护指引》，并确保小程序名称与主体信息正确。
- 按实际功能声明：
  - 微信登录对应的用户标识；
  - 用户主动选择或填写的头像、昵称；
  - 创建和履约所需的商品及订单信息；
  - 微信支付所需的订单号、金额和支付结果。
- 头像图片上传到自有服务器的用途应写明为“用户主动设置个人资料”。
- 不声明位置、通讯录、后台音频等当前代码未使用的能力。
- 平台声明项必须与实际接口行为、首页官方隐私弹窗和自有隐私说明保持一致。

## 4. 微信支付

- 确认小程序 AppID `wx39c20690901c74e4` 已绑定正确的微信支付商户号。
- 确认商户主体、经营类目、结算账户和 API 证书有效。
- 使用真实低金额订单完成一次下单、调起支付、取消支付和支付成功回跳测试。
- 不在审核说明中提供真实支付密钥、商户证书或管理员账号密码。

## 5. 提交前人工验收

- 先上传 11 张商品图，再执行并核验 `miniprogram_review_launch.sql`。
- 使用线上接口确认图片、分类、商品状态均正确。
- 在 HBuilderX 重新发行微信小程序包；不要直接提交当前旧的 `unpackage/dist/dev` 产物。
- 在微信开发者工具中开启合法域名校验，清缓存后从首次启动测试：
  1. 查看并打开微信官方隐私保护指引；
  2. 拒绝隐私授权后仍可浏览商品；
  3. 进入点单前出现 18 周岁确认，拒绝后返回首页；
  4. 未登录可浏览分类和详情；
  5. 登录后可加购、确认订单并调起支付；
  6. 断网、空列表和坏图片均有可理解的提示或占位图。
- 最后检查体验版，确认无开发版接口、无本地地址、无跳过域名校验设置。
