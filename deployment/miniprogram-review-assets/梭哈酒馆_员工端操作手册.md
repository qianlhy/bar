# 梭哈酒馆 · 员工端操作手册

**适用对象：** 吧台 / 前台员工账号  
**系统：** 梭哈酒馆后台管理系统（员工端）  
**权限说明：** 员工账号仅可使用 **订单管理**、**积分录入**；登录后默认进入订单页。不可进入首页、商品、分类、用户、充值、币商城、系统设置等菜单。

---

## 一、登录与退出

1. 浏览器打开后台地址（由店长 / 技术方提供）。  
2. 输入**员工账号**和密码登录。  
3. 登录成功后进入「订单管理」。  
4. 下班退出：右上角「员工账号」→「退出登录」。

---

## 二、你可以做什么 / 不能做什么

| 可以 | 不可以 |
|---|---|
| 查看订单列表与详情 | 点击「开始出品」「完成」（改订单状态） |
| 按状态筛选、按订单号搜索 | 改商品、分类、价格、库存 |
| 录入会员积分、查看积分流水 | 改用户资产、大师分、充值、币商城 |
| — | 改 WiFi、门店信息等系统设置 |

> 订单出品推进请联系**管理员账号**操作，或由店长分配管理员处理。

---

## 三、订单管理（查看）

### 3.1 看单

1. 左侧菜单点「订单管理」。  
2. 可按状态筛选：待付款 / 待出品 / 出品中 / 已完成 / 已取消。  
3. 可按订单号搜索。  
4. 核对：桌台号（顾客栏）、商品、规格、备注、实付、积分/币抵扣。

### 3.2 订单状态含义（只读了解）

| 状态 | 含义 |
|---|---|
| 待付款 | 顾客已下单，尚未支付 |
| 待出品 | 已支付，等待吧台制作 |
| 出品中 | 正在制作 |
| 已完成 | 已完成服务 |
| 已取消 | 已取消 |

### 3.3 查看详情

1. 点击「查看详情」进入订单明细。  
2. 可看商品清单、支付方式、备注、时间等。  
3. 进入详情会**锁定该订单**（避免多人同时处理）；看完离开即可释放。  
4. 员工端**没有**「开始出品」「完成」按钮；若需改状态，请管理员操作。

**营业建议：** 发现新的「待出品」单，及时口头/对讲通知吧台或管理员在后台推进状态。

## 四、积分录入（核心）

### 4.1 规则（务必向顾客说明）

- **100 积分 = 1 元**（下单抵扣时）  
- 单笔最多抵扣订单金额 **50%**（需门店已开启积分抵扣）  
- **每日 0 点自动清零**所有用户积分  

### 4.2 操作步骤

1. 左侧菜单点「积分录入」。  
2. 输入昵称或手机号 → 查询用户。  
3. 确认是本人后，点击「录入积分」（系统会先锁定该用户）。  
4. 填写：  
   - 积分数（按门店规定，如开台分、局分）  
   - 备注（建议写清来源，如「开台录入」「整局结算补录」）  
5. 确认提交。  
6. 下方「最近积分流水」可核对是否录入成功。

### 4.3 流水类型（只读）

| 类型 | 含义 |
|---|---|
| 手动录入 | 员工/管理员刚录入的 |
| 消费抵扣 | 顾客下单用积分抵扣 |
| 取消退回 | 订单取消等退回 |
| 每日清零 | 系统 0 点清零 |
| 每日签到 | 顾客小程序签到获得 |

### 4.4 注意

- 录入前确认用户身份，避免加错人。  
- 积分当日有效，打烊前录入更合理；跨日清零后需重新录入。  
- **不要**指望在「用户管理」里改积分——员工进不去该页；积分只能走本页录入。

## 五、日常简易 SOP

### 开班

1. 登录员工账号，确认能打开订单列表。  
2. 看一眼是否有未处理的「待出品」，通知管理员/吧台。

### 营业中

1. 顾客要加积分 →「积分录入」。  
2. 顾客问订单进度 →「订单管理」按状态或订单号查，如实告知。  
3. 需要改订单状态 → 找管理员。

### 交班

1. 告知下一班未完成订单情况。  
2. 退出登录。

## 六、常见问题

**Q1：为什么没有「开始出品」按钮？**  
A：员工账号设计如此，只能查单；改状态用管理员账号。

**Q2：搜不到用户？**  
A：核对昵称/手机号；确认顾客已用微信登录过小程序并注册会员。

**Q3：积分录进去了顾客说用不了？**  
A：可能已过 0 点被清零；或门店关闭了积分抵扣（需管理员在系统设置开启）。把情况报给店长。

**Q4：误给别人加了积分？**  
A：员工端无法扣回，立即报告店长/管理员处理。

**Q5：进不去商品管理 / 设置？**  
A：正常。员工账号无这些菜单；需要改价、改 WiFi 等请管理员操作。
