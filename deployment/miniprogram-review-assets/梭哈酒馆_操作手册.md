# 梭哈酒馆 · 操作手册

**适用对象：** 门店老板、店长、吧台员工、客户对接人  
**系统组成：** 微信小程序（顾客端）+ 后台管理系统（门店端）  
**版本说明：** 当前小程序为提审/上线精简版，以店内点单、支付、订单、积分为主；部分预付/兑换功能在小程序端已隐藏，后台仍保留配置能力。

---

## 一、系统简介

| 端 | 用途 | 谁用 |
|---|---|---|
| 微信小程序 | 顾客浏览商品、店内点单、微信支付、查看订单与排行 | 到店顾客 |
| 后台管理 | 商品上下架、接单出品、积分录入、用户与门店配置 | 管理员 / 员工 |

**业务主流程（店内）：**

顾客点单 → 微信支付 → 后台出现「待出品」订单 → 店员开始出品 → 完成出品 → 订单完成

---

## 二、微信小程序操作手册（顾客端）

### 2.1 进入小程序

1. 用微信扫码门店小程序码，或通过分享卡片进入。  
2. 首次进入可能看到**隐私保护提示**：可查看官方隐私指引后点击「同意并继续」；也可暂不授权，仍可浏览商品。  
3. 进入**点单**前，需确认「已满 18 周岁、理性饮酒」；拒绝后会返回首页。

### 2.2 底部导航说明

| Tab | 功能 |
|---|---|
| 首页 | 门店信息、会员码、立即点单、查看 WIFI |
| 点单 | 按分类浏览商品并加入购物车 |
| 排行榜 | 查看大师分排行 |
| 我的 | 登录、积分、订单、个人资料 |

### 2.3 首页

- **会员码**：登录后点击「会员码」，向店员出示（用于到店识别会员）。  
- **立即点单**：进入点单页。  
- **查看 WIFI**：显示门店 WiFi 名称与密码（后台可配置）。  
- **位置**：展示门店地址（后台可配置）。

### 2.4 点单与下单

1. 左侧选择分类，右侧浏览商品。  
2. 无规格商品：点击「+」加入购物车（需先登录）。  
3. 有规格商品：点击「选规格」→ 选择口味/规格 → 确认加入。  
4. 也可点进商品详情：加入购物车或立即购买。  
5. 底部购物车栏点击「去结算」。  
6. 确认订单页可填写：  
   - 桌台号（选填）  
   - 订单备注（选填）  
   - 是否使用积分抵扣（若门店已开启积分）  
7. 提交订单 → 进入支付页 → 微信支付。  
8. 支付成功后可在「订单中心」查看进度。

**说明：**

- 未登录可浏览商品；加购、下单、支付前需登录。  
- 当前为**店内点单**，非外卖配送。  
- 积分规则（后台开启时）：约 **100 积分 = 1 元**，单笔最高抵扣订单金额 **50%**；积分每日 0 点清零（以系统设置为准）。

### 2.5 登录与个人中心

1. 「我的」→「注册会员 / 登录」。  
2. 使用微信授权登录；可完善头像、昵称。  
3. 「个人中心」可修改资料。  
4. 「订单中心」可查看各状态订单，待付款订单可继续支付或取消。  
5. 「大师分」可进入排行榜。

### 2.6 当前小程序不展示的功能（提审精简）

以下入口已隐藏，避免顾客或审核员进入未完成/无资质页面：

- 房台预定、我的存酒  
- 会员充值、All In 币商城 / 兑换  
- 优惠券、地址管理、空联系电话入口  

后续若取得资质并完成功能，可由技术方恢复入口。

## 三、后台管理系统操作手册（门店端）

### 3.1 登录

1. 浏览器打开后台地址（由服务方提供，示例：`https://您的域名/admin/`）。  
2. 输入管理员 / 员工账号密码登录。  
3. 退出：右上角头像菜单 →「退出登录」。

### 3.2 账号角色权限

| 角色 | 可使用菜单 |
|---|---|
| 管理员 | 全部菜单（首页、分类、商品、订单、积分、用户、排行、币商城、充值、系统设置等） |
| 员工 | 主要使用：**订单管理**、**积分录入**（登录后默认进入订单页） |

### 3.3 首页（仪表盘）

用于查看经营概览数据（订单、商品等统计）。建议每日开店前看一眼是否有异常待处理订单。

### 3.4 分类管理

1. 进入「分类管理」。  
2. 可新增 / 编辑分类名称、排序、启用状态。  
3. **禁用**的分类不会在小程序点单页展示。  
4. 无对应经营资质的分类（如水烟、槟榔等）请保持下架/禁用。

### 3.5 商品管理

1. 进入「商品管理」。  
2. 可新增 / 编辑：名称、分类、价格、原价、库存、主图、详情、规格、上下架状态。  
3. **上架**：小程序可见；**下架**：小程序不可见。  
4. 规格示例：啤酒口味（樱桃 / 桃子）等，顾客需在小程序选规格后下单。  
5. 建议商品图使用清晰 1:1 实拍或合规商品图，避免空白图影响体验与审核。

### 3.6 订单管理（核心）

订单状态说明：

| 状态 | 含义 | 常见下一步 |
|---|---|---|
| 待付款 | 顾客已下单未支付 | 等待支付；超时可能自动取消 |
| 待出品 | 已支付，等待吧台制作 | 管理员点击「开始出品」 |
| 出品中 | 正在制作 | 管理员点击完成出品 |
| 已完成 | 已完成服务 | 无需操作 |
| 已取消 | 已取消 | 无需操作 |

**推荐店内操作：**

1. 打开「订单管理」，筛选「待出品」。  
2. 核对桌台号、商品、规格、备注。  
3. 开始出品 → 制作完成 → 标记完成。  
4. 点进订单详情可查看完整商品明细与支付信息。

> 员工账号也可进入订单列表处理；部分状态变更按钮可能仅管理员可见，请按门店分工执行。

### 3.7 积分录入

1. 进入「积分录入」。  
2. 可按昵称 / 手机号搜索用户。  
3. 点击「录入积分」，填写增加分值与备注。  
4. 下方可查看最近积分流水。  
5. 顾客下单时可按规则抵扣（需在系统设置中开启积分抵扣）。

**注意：** 积分有清零规则（当前为每日 0 点清零），录入前请与顾客说明清楚。

### 3.8 用户管理

1. 查看注册会员列表。  
2. 可查看昵称、头像、积分等相关信息。  
3. 用于到店核对会员、配合积分录入。

### 3.9 大师分排行榜

后台可查看大师分排行数据；小程序「排行榜」页面对顾客展示。

### 3.10 All In 币商城 / 会员充值（后台保留）

后台仍可见：

- All In 币商品管理、兑换记录  
- 充值套餐、充值订单  

**当前说明：** 因小程序端已隐藏相关入口，顾客暂时无法在小程序内充值/兑换。后台可先做配置预留；正式对客开放前，请确认预付卡等资质齐全，并通知技术方恢复小程序入口。

### 3.11 系统设置

#### 门店信息 / WiFi

可配置并保存：

- 门店名称  
- 门店地址  
- 门店电话  
- WiFi 名称、WiFi 密码  
- 充值说明文案（预留）

保存后，小程序首页地址 / WIFI 等信息会同步展示。

#### 积分抵扣设置

- 开关：开启后顾客下单可使用积分  
- 比例：100 积分 = 1 元（固定）  
- 上限：单笔最多抵扣订单金额 50%（固定）  
- 清零：每日 0 点自动清零（固定规则）

#### 微信 / 支付相关配置

用于配置小程序 AppID、密钥及支付相关参数。  
**请勿把密钥截图发给无关人员；修改前建议联系技术方确认，避免支付中断。**

## 四、日常运营建议 SOP

### 开店前

1. 后台登录正常。  
2. 确认今日上架商品、价格、库存正确。  
3. WiFi、门店地址信息正确。  
4. 检查是否有「待出品」积压订单。

### 营业中

1. 及时处理「待出品 / 出品中」订单。  
2. 按桌台号出品，避免错单。  
3. 需要给会员加分时，走「积分录入」。

### 打烊后

1. 确认无未完成出品订单。  
2. 必要时导出/核对当日订单（如有报表需求可联系技术方）。  
3. 退出后台账号。

## 五、常见问题

**Q1：顾客说加不了购物车？**  
A：需先登录；未登录只能浏览。

**Q2：点单进不去？**  
A：需在成年饮酒提示中点击确认；若一直返回首页，清缓存后重试或联系技术方。

**Q3：支付成功但后台看不到？**  
A：刷新订单列表；确认筛选状态不是「已取消」；仍无则核对微信支付回调与网络，联系技术方。

**Q4：商品图空白？**  
A：到后台商品管理检查是否上传图片；确认图片可公网访问。

**Q5：积分抵不了？**  
A：检查系统设置中积分开关是否开启；确认用户当日有积分且未超过抵扣上限。

**Q6：为什么小程序没有充值 / 币商城？**  
A：当前版本为合规提审精简版已隐藏；后台仍可预配置，开放时再恢复入口。
