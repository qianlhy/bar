# 梭哈酒馆 · 操作手册（定版）

**品牌：** 梭哈酒馆 / ALL IN TAVERN · 南京店  
**适用对象：** 门店老板、店长、吧台员工、客户对接人  
**系统组成：** 微信小程序（顾客端）+ 后台管理系统（门店端）  
**版本说明：** 定版已对客开放店内点单、微信支付、积分签到、会员充值、All In 币商城、店内环境与电话预定等完整能力；以本文为准。

---

## 一、系统简介

| 端 | 用途 | 谁用 |
|---|---|---|
| 微信小程序 | 浏览商品、店内点单、支付、签到、充值、币兑换、排行榜、门店信息 | 到店顾客 |
| 后台管理 | 商品上下架、接单出品、积分录入、用户与资产、币商城/充值配置、门店设置 | 管理员 / 员工 |

**核心业务链路：**

1. **堂食点单：** 顾客点单 → 微信支付（或 All In 币 / 混合支付）→ 后台「待出品」→ 开始出品 → 完成  
2. **积分：** 每日签到 / 店员录入 → 下单可抵扣（需开启）→ 每日 0 点清零  
3. **All In 币：** 会员充值到账 → 支付抵扣或币商城兑换

## 二、微信小程序操作手册（顾客端）

### 2.1 进入小程序

1. 用微信扫码门店小程序码，或通过分享卡片进入。  
2. 首次进入可能出现**用户隐私保护提示**：可查看官方隐私指引后点「同意并继续」；也可「暂不授权」继续浏览商品。  
3. 进入**点单**或提交订单前，需确认「已满 18 周岁、理性饮酒」；拒绝后返回首页。

### 2.2 底部导航

| Tab | 功能 |
|---|---|
| 首页 | 品牌展示、会员码、积分/币、点单、币商城、充值、签到、WiFi、门店与预定 |
| 点单 | 按分类浏览商品并加入购物车 |
| 排行榜 | 大师分排行（本月 / 上月 / 本季度 / 上季度） |
| 我的 | 登录、资产、订单、币商城、充值、个人中心 |

### 2.3 首页功能一览

| 入口 | 说明 |
|---|---|
| 会员码（顶栏「码」/ 会员条 / 会员特权） | 登录后出示二维码，供店员识别会员 |
| 我的积分 / All In 币 | 展示当前资产 |
| 立即点单 | 进入点单 Tab |
| 币商城 | 用 All In 币兑换商品（需登录） |
| 会员充值 → 立即充值 | 购买充值套餐，到账为 All In 币（需登录） |
| 每日签到 | 每日一次，成功后获得积分；已签显示「今日已签」 |
| 查看 WiFi | 弹窗显示 WiFi 名称与密码（后台可改） |
| 门店地址 / 导航 | 查看地址；打开地图导航或复制地址 |
| 立即预定 / 拨打电话 | **拨打门店预定电话**（非小程序内在线订座） |
| 店内环境 | 浏览门店环境图（后台可上传多图） |
| 顶栏「设」 | 进入设置（需登录） |

页脚免责声明：绿色竞技，禁止赌博；筹码仅作计分牌，无现金价值。技术支持：熠火。

### 2.4 点单与下单

1. 左侧选分类，右侧浏览商品（名称、描述、销量、价格）。  
2. 无规格：点「+」加入购物车（需先登录）。  
3. 有规格：点「选规格」→ 选择后确认加入。  
4. 可进商品详情：加入购物车或立即购买。  
5. 底部购物车栏 →「去结算」。  
6. 确认订单页可填写：  
   - 桌台号（选填）  
   - 订单备注（选填）  
   - 是否使用积分抵扣（门店已开启积分时显示）  
7. 提交订单 → 支付页可选：  
   - **微信支付**  
   - **All In 币支付**（1 币 = 1 元）  
   - **混合支付**（微信成功后再扣币）  
8. 支付成功后可在「订单中心」查看进度。

**说明：**

- 未登录可浏览；加购、下单、支付、签到、充值、币商城前需登录。  
- 当前为**店内点单**，非外卖配送；服务费为 ¥0.00。  
- 积分规则（后台开启时）：**100 积分 = 1 元**，单笔最高抵扣订单金额 **50%**；积分**每日 0 点清零**。

### 2.5 会员充值与 All In 币商城

**会员充值**

1. 首页「立即充值」或「我的」→「会员充值」。  
2. 选择套餐 → 支付。  
3. 充值金额按套餐到账为 **All In 币**（页面说明：1 币 = 1 元）；部分套餐可能另赠币（以后台配置为准）。  
4. 若订单为「待支付」，店员可在后台「充值订单」中确认到账。

**币商城**

1. 首页「币商城」或「我的」→「币商城」。  
2. 查看「我的 All In 币」，选择商品点「兑换」。  
3. 「兑换记录」可查看历史兑换。  
4. 实物/酒水兑付以门店线下履约为准（后台兑换记录为只读流水）。

### 2.6 登录与个人中心

1. 「我的」→「注册会员」→ 微信授权登录；需勾选同意《用户协议》《隐私政策》。  
2. 「个人中心」（设置）：修改资料、清除缓存、关于我们、协议入口、退出登录。  
3. 「订单中心」：全部 / 待付款 / 待出品 / 出品中 / 已完成 / 已取消；待付款可继续支付或取消。  
4. 「大师分」：进入排行榜。  
5. 资产入口：All In 币数字可进充值页；积分在首页与「我的」展示。

### 2.7 排行榜

- 子榜：本月榜、上月榜、本季度榜、上季度榜。  
- 展示昵称、头像、大师分；分数由后台维护。

### 2.8 当前未对客展示的能力

以下页面或能力**定版未挂入口**（不影响主流程）：

- 我的收藏、商品搜索（页面已预留，暂无导航）  
- 收货地址管理、我的存酒、优惠券中心  

「立即预定」仅为**电话预定**，不是在线订座系统。

## 三、后台管理系统操作手册（门店端）

### 3.1 登录

1. 浏览器打开后台地址（由服务方提供，示例：`https://您的域名/admin/`）。  
2. 输入管理员 / 员工账号密码，进入「梭哈酒馆管理系统」。  
3. 退出：右上角账号菜单 →「退出登录」。

### 3.2 账号角色权限

| 角色 | 界面显示 | 可使用菜单 |
|---|---|---|
| 管理员（role 1 / 2） | 管理员账号 | 全部：首页、分类、商品、订单、积分、用户、排行、All In 币商城、会员充值、系统设置 |
| 员工（role 3） | 员工账号 | **仅**订单管理、积分录入；登录后默认进入订单页 |

**员工限制补充：**

- 可查看订单列表与详情、搜索筛选。  
- **不能**点击「开始出品」「完成」（订单状态推进需管理员）。  
- 积分录入权限与管理员相同。

### 3.3 首页（运营概览）

- 统计：待付款 / 待出品 / 出品中 / 已完成订单数量。  
- 支持 WebSocket 新订单提醒与浏览器语音播报；状态显示「服务在线 / 连接中断」。  
- **建议营业中保持首页开启**，以便及时收到新单提醒。

### 3.4 分类管理

1. 添加 / 编辑 / 删除分类。  
2. 字段：名称、图标、排序、状态（启用 / 禁用）。  
3. **禁用**的分类不在小程序点单页展示。  
4. 图标建议约 100×100，JPG/PNG/WEBP/GIF，≤ 5MB。

### 3.5 商品管理

1. 添加 / 编辑 / 删除商品；可按名称搜索。  
2. 字段：名称、分类、价格、原价、库存、描述、详情、主图、轮播图、状态。  
3. **上架**小程序可见；**下架**不可见。  
4. 有规格的商品顾客需在小程序选规格后下单。  
5. 主图建议约 800×800，清晰实拍，≤ 10MB。

### 3.6 订单管理（核心）

**订单状态：**

| 状态 | 含义 | 常见下一步 |
|---|---|---|
| 待付款 | 已下单未支付 | 等待支付；超时可能取消 |
| 待出品 | 已支付，等待制作 | 管理员点「开始出品」 |
| 出品中 | 正在制作 | 管理员点「完成」 |
| 已完成 | 已完成服务 | 无需操作 |
| 已取消 | 已取消 | 无需操作 |

**支付方式显示：** 微信支付 / All In 币 / 混合支付 / 店内支付。

**推荐店内操作：**

1. 打开「订单管理」，筛选「待出品」。  
2. 核对桌台号（顾客名栏）、商品、规格、备注、实付与积分/币抵扣。  
3. 管理员：开始出品 → 制作完成 → 完成。  
4. 进入详情可看完整明细；进入详情会**锁定订单**，避免多人同时处理，离开后释放。

### 3.7 积分录入

1. 按昵称 / 手机号搜索用户。  
2. 点击「录入积分」（需先锁定用户）→ 填写分值与备注（如「开台录入」）。  
3. 下方查看最近积分流水。  

**流水类型：** 手动录入、消费抵扣、取消退回、每日清零、每日签到。

页头提示：**100 积分 = 1 元 · 每日 0 点清零**。录入前请向顾客说明清零规则。

### 3.8 用户管理

1. 查看会员列表：昵称、头像、手机、余额、All In 币、大师分、积分等。  
2. **调整资产**：可改余额、All In 币、大师分、优惠券数量。  
3. **积分不能在此调整**，请走「积分录入」。  
4. 状态「正常 / 禁用」仅展示，后台无切换开关。

### 3.9 大师分排行榜

- 按昵称搜索；查看排名与大师分。  
- 可「修改分数」；小程序排行榜同步展示。

### 3.10 All In 币商城

**商品管理**

- 添加 / 编辑 / 删除币商品。  
- 字段：名称、图片、所需 All In 币、库存、排序、上架 / 下架。

**兑换记录**

- 只读：用户、商品、消耗币、时间。  
- **无核销状态**，线下兑付请门店自定流程（如打勾台账）。

### 3.11 会员充值

**充值套餐**

- 字段示例：套餐名称（如「充 100 送 20」）、实付金额、到账余额（元）、赠送 All In 币、排序、上架 / 下架。  
- 小程序充值页展示已上架套餐；「充值说明」文案在系统设置中配置。

**充值订单**

| 状态 | 含义 |
|---|---|
| 待支付 | 顾客已下单未到账 |
| 已到账 | 余额 / 币已入账 |
| 已取消 | 已取消 |

- 对待支付订单可点「确认到账」（到账余额 + 赠送币）。  
- 也可在用户管理中直接调整 All In 币（特殊补录场景）。

### 3.12 系统设置

#### 门店信息 / WiFi / 店内环境

可配置并保存：

- 门店名称、地址、电话、营业时间  
- 门店经纬度（导航用）  
- WiFi 名称、WiFi 密码  
- 充值说明（小程序充值页文案）  
- **店内环境图**（多图，建议横图 16:9；JPG/PNG/WEBP/GIF ≤ 10MB）

保存后，小程序首页地址、电话、WiFi、营业时间、店内环境等会同步。

#### 积分抵扣设置

- 开关：开启后顾客下单可用积分  
- 固定规则：100 积分 = 1 元；单笔最高抵扣 50%；每日 0 点清零  

#### 微信 / 上传 / 通知相关项

设置页中部分微信、上传、通知字段为界面预留；**实际密钥与支付参数在服务器配置文件中维护**。修改前请联系技术方，避免支付中断。请勿把密钥截图发给无关人员。

## 四、日常运营 SOP

### 开店前

1. 后台登录正常；首页通知「服务在线」。  
2. 确认今日上架商品、价格、库存正确。  
3. 核对 WiFi、地址、电话、营业时间、店内环境图。  
4. 确认充值套餐、币商城商品状态符合当日活动。  
5. 检查是否有积压的「待出品」订单。

### 营业中

1. 及时处理「待出品 / 出品中」订单，按桌台号出品。  
2. 需要给会员加分时走「积分录入」，并说明当日清零规则。  
3. 顾客出示会员码时，用于识别会员、核对资产。  
4. 电话预定：接听后按门店自有订座流程记录（系统不管理订座台账）。  
5. 币商城兑换：核对兑换记录后线下发货 / 出品。  
6. 充值异常（已付未到账）：在「充值订单」确认到账或联系技术方。

### 打烊后

1. 确认无未完成出品订单。  
2. 必要时核对当日订单与充值到账情况。  
3. 退出后台账号。

## 五、常见问题

**Q1：顾客说加不了购物车？**  
A：需先登录；未登录只能浏览。

**Q2：点单进不去 / 一直回首页？**  
A：需在成年饮酒提示中点确认；可清缓存后重试，或联系技术方。

**Q3：支付成功但后台看不到订单？**  
A：刷新订单列表；确认筛选不是「已取消」；仍无则核对微信支付回调，联系技术方。

**Q4：商品图空白？**  
A：后台商品管理检查是否上传图片，并确认图片可公网访问。

**Q5：积分抵不了？**  
A：检查系统设置中积分开关；确认用户当日有积分且未超 50% 上限；注意每日 0 点清零。

**Q6：签到没有积分？**  
A：确认已登录；每日仅可签到一次；已签会显示「今日已签」。

**Q7：All In 币支付失败或混合支付只扣了微信？**  
A：确认币余额充足；混合支付为微信成功后再扣币。异常订单保留订单号联系技术方。

**Q8：充值后币没到账？**  
A：到后台「充值订单」查看状态；待支付可「确认到账」；或用户管理中核对 All In 币。

**Q9：顾客兑换了币商品但没拿到东西？**  
A：后台「兑换记录」核对后线下履约；系统无自动核销状态，建议门店自备台账。

**Q10：WiFi 密码不对？**  
A：到系统设置修改 WiFi 密码并保存；顾客重新打开「查看 WiFi」即可（无需发版）。

**Q11：员工点不了「开始出品」？**  
A：员工账号仅可查看订单；状态推进请用管理员账号，或调整账号角色。

**Q12：「立即预定」没反应？**  
A：确认系统设置中已填写门店电话；预定为拨号，需手机授权通话。
